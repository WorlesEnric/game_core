## Defects fixed after real failures

1. `ManagedResources.cs` used array indexing on GC-022's `LinkedList<Id128>` in three GC-023 telemetry loops. Iterate linked-list nodes. The first full .NET build had three CS0021 errors; the final solution build/tests passed.
2. `Gc020TraversalHost` lacked `partial`, despite W6's second declaration. The first Unity resolve failed CS0260. Corrected the declaration.
3. The gate source checker included Unity's generated `Library` package cache, inventing unrelated duplicate type names and failing after an actual Unity import. Pruned generated `Library`, `bin`, `obj` and disposable release clone directories from its source walk. The real source audit then passed.
4. W6 scenario used members absent from `IW6Family` and `PipelineDescriptorReport`, passed an `int` where `TargetRegistry` requires `uint`, and called `ActionSurface()` on cards/narrative. Use `IGc020Family` for traversal-only facts, the report's `Descriptor.Stages`, a checked capacity cast and a reference course surface for the audit. `LifecyclePlayModeMatrix` also lacked its probe-host namespace import. Unity compilation then passed.
5. The first EditMode suite failed 25 W6 cases. W6's test helper failed to find the fixture-prefixed observation; fixed name matching without changing any pass criterion. The W6 physics scene requires actual PlayMode, so classify its existing test assembly as PlayMode (as GC-020 already does); all 27 original tests remain enabled.
6. The cycle loop bound its lifecycle controller **after** its first provider publication, which P-030 forbids. Bind at fixture construction before publication. The card delivery check compared a committed card *result* event to the destination *command* schema; compare to `CardTableKeys.ResultSchema`. It also compared the adapter's explicit acknowledgement to `WorldDeliveryOwner.AcknowledgedCount`, which only increments for acknowledgements inside the owner's dispatch loop; assert the adapter's acknowledged outcome and empty outbox instead. None of the expected gameplay values changed.
7. The stress ledger check demanded zero live callbacks even while two deliberately retained genre providers remain mounted. Compare to the measured post-build provider baseline; still require zero cycle-owned lease, no quarantine and stable ledger/fence counts. Give generated and fixture runs distinct session identity streams so the fixture cannot rejoin the generated world's epoch-2003 host. The W6 scenario's `finally` had omitted `TearDownSafely`, leaving its worlds registered; restored it. In PlayMode the application bootstrap legitimately retains one world, so the suite checks that the registry returns to its **pre-run baseline** rather than erasing the application-owned world.
8. A local physics scene unload is asynchronous. Several W6 course worlds created within one frame collided on the same scene name; use a distinct ordinal scene name per attachment. The cost observation previously admitted five fixed steps but simulated zero; simulate once immediately after each admitted step. These fixes made its engine counts observable instead of weakening them.
9. Traversal's input stage decoded movement and freed its buffer but left external requests `Accepted` forever; on the ninth step, the bounded request ledger correctly backpressured. Settle each decoded movement request through `WorldMessagePlane.Commit` before writing the captured input, emitting the committed movement event; refusal still rejects through the existing path. The corrected 1,000-cycle run proves the formerly failing capacity boundary. `UnityLifecycleWorldBinding.CountAttributedRows` only counted the ranked provider of an additive row; it now counts a row when the installation appears in its canonical support set. This restores support attribution for a modifier alongside the already-mounted provider.
10. Fixture-catalog digest literals included the `fixture:` prefix but `W6GateScenarioResult` hashed unprefixed names. Compute the fixture digest with that prefix while preserving the combined list's already-prefixed display names. No literal changed. The initial built release-surface check failed because its scanner read managed DLLs and generated C++ but not IL2CPP `global-metadata.dat`, where mode-flag strings actually reside. Include the metadata in both operands; it then found all qualification anchors, the retained traversal flag in both players, and zero forbidden release markers.

Every fix was committed and pushed in logical commits before final evidence. Historical failing targeted XML/logs remain alongside the final accepted XML/logs and are **not** counted as passes; the final gate was rerun end-to-end after the release scanner fix. The full gate did not encounter the known intermittent pre-dispatch hang on its accepted run. No test expected value was changed and no test was weakened, skipped or deleted.
