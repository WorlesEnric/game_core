## Fixes

1. `AssemblyPublisher.Publish`: define `nextEpoch` and `nextRevision` from the adopted publication before stamping/committing; missing locals blocked Unity compilation.
2. `UnityExecutionDriver`: supply an `OperationId` rather than `WorldId` to the structural fault record (world/session/step-derived identity); Unity compiler rejected the old argument.
3. `InitialDefinitionRecovery`: import the existing `GameCore.Execution.GameCoreThreading` namespace; absent import blocked Unity compilation.
4. `FaultScenario`: qualify `global::Unity.Entities.Entity` and join the `IReadOnlyList<string>` through `IEnumerable<string>`; both were Unity compile errors. Corrected provenance assertion to name the derivation operation used by the publisher. Corrected migration fixture to use an actually declared/registered migration where available, avoiding fabricated schema-0 slots that made the planner reject before the latch. Corrected postwrite host-vs-driver fault assertions and retained-resource expectation for a faulted-but-not-yet-stopped world. All 15 names/digests remain unchanged.
5. `RecoveryFixture`: second publication now reads actual current live slot schemas after first publication migrated 1→2, rather than reusing stale schema-1 seeded input. Kept the first migration case. Changed absolute fault reach expectation to a delta, since the first successful publication already reached the unarmed boundary. `InitialDefinitionRecoveryTests` now checks recovery adds no reaches to that baseline rather than incorrectly asserting one lifetime reach. No expected protocol value changed.
6. Probe script: C# boolean detail prints `True`, not lowercase `true`; corrected the script's fragment so it verifies the actual recorded successful lease release rather than rejecting five passing player results.
7. Release switch: `com.unity.test-framework` is brought in **transitively** by Unity packages, so the original asmdef version define remained enabled even after removing direct test dependencies. Added an explicit `com.gamecore.fault-qualification` marker package only to the validation project's manifest, and switched the runtime asmdef define to that marker; updated error text. Unity regenerated `Packages/packages-lock.json`.

No tests were ignored, skipped, deleted or weakened to pass. `artifacts/gates/w4-generic-profile/inventory.json` was not promoted: this job produced fault evidence, not that inventory's generic-profile measurements.
