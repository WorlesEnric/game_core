## Where the design came from

The design came out of four multi-agent reviews on 2026-09-28. Each one read the game_core and etos code
(read-only) and had adversarial verification:

1. Choosing a UI host (Unity Editor extension vs a standalone app). This was superseded by the Studio design.
2. Evaluating the AI-driven vision: GameCore extension tree → etos RG, transaction agents, and a player-window
   Studio.
3. The Studio design for the owner's decisions D1–D5: code blocks as assets, player profiles, and etos core
   unchanged. The design was red-teamed from a kernel/Unity lens and an etos lens, then revised.
4. Two follow-up checks: D7 (transaction agents maintained in game_core) and D8 (agents publishing artifacts
   directly). These were folded into [design.md §7](design.md#7-transaction-agents).
