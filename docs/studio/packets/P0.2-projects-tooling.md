### 3. Host scripts (`studio/tools/`, bash, `set -euo pipefail`, ASCII, usage in the header)

**No builds on the Mac.** Nothing is compiled, built or tested on the Mac (owner rule); the Mac runs only the
interpreter-level checkers. Code reaches the host only through git, never rsync.

- `sync-to-host.sh [--wip] <packet>` (git-based since the follow-up packet; the first version used rsync):
  1. requires a clean tree; with `--wip` it warns and snapshots the uncommitted state as one temporary commit on
     `wip/<packet>` (built in a private index, parent `HEAD`), leaving the current branch, index and working tree
     untouched. It never commits on the current branch;
  2. adds the git remote `host` (`myubuntu:wkspace/gc-studio/hub.git`) if missing, creates the bare hub if it
     is missing, and force-pushes the branch (current branch, or `wip/<packet>`);
  3. on the host, `~/wkspace/gc-studio/<packet>` becomes a clone of the hub at that branch: `git clone
     --reference-if-able ~/wkspace/game_core` when absent (alternates, no `--dissociate`: objects the host
     checkout already has, including the `artifacts/` history, are borrowed instead of transferred; override with
     `GC_STUDIO_REFERENCE`), else `fetch` + `checkout -B` + `reset --hard origin/<branch>` + `git clean -fd`
     (untracked non-ignored files only, with `Library/ Temp/ Logs/ UserSettings/ .unity-logs/` excluded). Unity
     `Library/` caches therefore survive every sync. A directory left by the old rsync version is replaced by a
     clone with its `Library/` directories and `.unity-logs/` moved across. The host clone's `HEAD` is checked
     against the pushed sha.
- `unity-compile.sh <packet> <project> [--tests EditMode|PlayMode] [--filter <regex>]`: runs on the host (re-runs
  itself there over ssh when started on the Mac). At most `GC_STUDIO_UNITY_SLOTS` (3) batchmode Editors
  host-wide: flock slots in `~/wkspace/gc-studio/.unity-slots/` plus a count of all running batchmode Editors
  (import workers excluded); waits otherwise. `timeout --kill-after=60 1500` plus a log-silence watchdog
  (`UNITY_SILENCE_TIMEOUT`, 600 s), retry exactly once on a timeout/silence kill, never on a real error. Prints
  error lines, the test summary and failed tests; exit 1 on compile errors, failed tests, missing results or zero
  selected tests. Logs/XML in `~/wkspace/gc-studio/<packet>/.unity-logs/`.
- `dotnet-test.sh <packet> [project] [-- args]`: host `~/.dotnet/dotnet test` (default `dotnet/GameCore.sln`),
  `GAMECORE_OFFLINE` 0/1 exactly as `docs/operator/build-and-run.md` §2.1 (1 adds `-p:NuGetAudit=false` to this
  invocation only; any other value is refused).
