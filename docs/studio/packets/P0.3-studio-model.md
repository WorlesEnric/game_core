Design notes:
- Every shape is an immutable `sealed class` with a constructor, `[JsonObject(MemberSerialization.OptIn)]` and an
  explicit camelCase `[JsonProperty]`. Required members are `Required.Always`. A plain `JsonConvert` call produces
  the same keys (tested).
- **Null policy (03 s9).** Every optional member is
  `[JsonProperty(Required = DisallowNull, NullValueHandling = Ignore)]`. So it is omitted when absent, never
  written as `null`, and a JSON `null` is refused on read with "Required property 'x' expects a non-null value".
  Because the rule sits on the members, it holds for any Newtonsoft caller, not only `StudioJson` (tested both
  ways). The schemas keep optional members as their plain type (`type: string`, ...). `IndexField` turns a
  `JValue` null into an absent value.
- `StudioJson` adds the remaining strict read rules: unknown members refused, trailing content refused, no date
  sniffing inside free-form `args`, `'\n'` newlines. A constructor null guard is reported as
  `JsonSerializationException`.
- Enums are always strings. `StrictStringEnumConverter` accepts only the exact documented spelling, so it refuses
  integers, other casings and comma-joined flags. The lowercase spellings come from `[EnumMember]`.
- Optional arrays are nullable, so documents round-trip exactly. `EffectiveState` (Requested) and
  `EffectivePolicy` (AllOrNothing) supply the defaults for an absent `state`/`policy`.
- `ChangeSet` is immutable; lifecycle progress uses `With*` copies.
- **Catalog revision.** `ToolCatalog.revision` is the lowercase sha256 hex of
  `StudioJson.Canonical(catalog without revision)`: keys sorted ordinally at every level, no whitespace, values as
  Newtonsoft writes them (e.g. `6.0`), UTF-8. `ComputeRevision()`, `WithRevision()` and `HasValidRevision()` are
  provided. `ToolCatalogBuilder.Build` and `ToolCatalog.Merge` mint it. The sample's revision
  (`5030be2d...9266`) was computed by an independent Python canonicalizer, and the C# result matches it.
- **asmdef is Editor-only** (`includePlatforms: ["Editor"]`). The model serves Studio (Editor) and is the source
  of the JSON contract. The companion uses the JSON and the schemas, not this DLL, so no player build carries it.
  That also sidesteps IL2CPP/AOT preservation of the Newtonsoft constructor-based types.

## Contract decisions (all decided by Fable, 2026-10-04)

1. **TargetId** = `StableNameKeyDerivation.Derive("auth." + authoringId)`, through the kernel helper with no
   parallel SHA rule. P0.5's Rust mirror must use `"auth." + id`.
2. **Index node `type`** is the `[Authorable]` type id (03 s3 updated).
3. **Structural rules** (cycles, duplicate op ids, artifacts, requirements, outcomes for unknown ops, candidate-mode
   fields) use `CandidateInvalid`; the message names the rule.
4. **Diagnostic** is `{code, message, hint?, where?, data?}`. `where` is absent for change-set-wide findings.
   - A target that exists but changed is `Conflict` with `data {expected, actual}`. That covers the op target
     stamp versus the index, and base versions versus the index.
   - A target that is gone (not in the full index) is `StaleTarget`.
   - A stamp-precondition op without a target stamp is `CandidateInvalid`.
   - `CheckStamps=false` turns stamp comparison off.
5. **Candidate mode** (`ChangeSetValidationOptions.Mode = ValidationMode.Candidate`) refuses each of these as
   `CandidateInvalid`:
   - a `state` other than absent/`Candidate`;
   - any `outcomes` (even `[]`);
   - `timestamps.applied`;
   - `links.gameCoreOps` (even `[]`).

   In every mode, each `outcomes[].opId` must name an operation.
6. **Scope rule.** When the tool's `scopes` or the target object type's `scopes` restrict scopes, the target must
   carry a `scope` inside the restriction. An absent `scope` is `ScopeNotAllowed`, because an unstated scope cannot
   satisfy a restriction.
7. **Index completeness.** Two rules are sound only against the full index: "target not in the index"
   (`StaleTarget`) and Project prerequisites. `IndexIsSlice = true` skips both. Every other index rule judges only
   what the slice contains.
8. Earlier additions accepted:
   - `AuthorValidatorAttribute(id){Codes}`;
   - `AuthorOperation.Requires/RequiresOnTarget/Scope/TargetKinds`;
   - `AuthorArg/AuthorField.Type`;
   - `AuthorArg.Name/Category/Required`;
   - the `ObjectTypeId` property name.

Validator rules, in output order:
1. Envelope (`CandidateInvalid`): schema id, change-set id, `links.parent`, empty operations.
2. Candidate mode only (`CandidateInvalid`): state, outcomes, `timestamps.applied`, `links.gameCoreOps`.
3. Op ids, outcomes, dependencies (`CandidateInvalid`): duplicate opIds, outcomes for unknown ops, unknown
   `dependsOn`, and cycles (Kahn; each cycle reported once, at its first member in document order).
4. Per operation:
   - `UnknownTool`.
   - Target: missing target, kind not in `targetKinds`, or node type not equal to `targetType` → `InvalidArgs`;
     malformed ref → `CandidateInvalid` at the ref; absent from the full index → `StaleTarget` at the ref
     (skipped for a slice).
   - Scope: not allowed by the tool or the object type, or absent under a restriction → `ScopeNotAllowed`.
   - Stamps: stamp-precondition op without a stamp → `CandidateInvalid`; stamp differs from the index →
     `Conflict` with `data {expected, actual}`.
   - Prerequisites: Target → `MissingPrerequisite`; Project → `MissingPrerequisite` (skipped for a slice).
   - Arguments → `InvalidArgs`: unknown, missing required, wrong type, out of min/max, enum value, vector arity,
     `ref` category (when the referenced node is in the index), artifact shape.
   - `applyRequirement` weaker than the tool's → `CandidateInvalid`.
5. Artifacts (`CandidateInvalid`): bad digest, duplicate, referenced but not carried, carried but used by no op.
6. Requirements (`CandidateInvalid`): `max` or a flag under-declared relative to the ops, internal inconsistency,
   requirements missing when the ops need more than Live.
7. Base versions: bad stamp → `CandidateInvalid`; stamp differs from the index → `Conflict` with
   `data {expected, actual}`.

Regenerate the schemas after any model change: `python3 tools/studio/emit_studio_schemas.py` on the host. The test
`SchemaTests.CommittedSchemasAreCurrent` fails until you do.
