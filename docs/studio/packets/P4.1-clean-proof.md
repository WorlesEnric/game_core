# P4.1 — Saltmarsh clean-project proof

Branch: `codex/p4.1`. Implementation and qualification on Linux host myubuntu only.

## Scope

A fresh project at `games/cleanproof`, with a lighthouse island, Harbour / Dunes / Lighthouse,
Ada / Neri / Sol, and the three-stage Relight the Coast quest. Recover sea glass or use the
keeper's spare lens; restoring the beacon protects the harbour and changes the ending text.
Four items, package UI screens, three procedural ambiences and one procedural music state.
All media is procedural placeholder content; no ETOS or paid operations are used.

`studio/tools/new-project.sh games/<name> [DisplayName]` copies the content-free template
under `games/cleanproof/Template~`, creates exact pinned package references and preserves
existing files. Run the shared Unity wrapper with `-quit -executeMethod GameCoreProjectSetup.Configure`
to configure URP, Input System, AI Navigation defaults, IL2CPP, Boot and build settings.
Unity resolves the lock on this host; no Library or lock is copied from Hollowmere.
